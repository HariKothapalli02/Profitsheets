2. INSTANT PRE-PAINT SCROLL RESTORATION FIX
--------------------------------------------------------------------------------
- Problem: Navigating between pages (e.g., from the bottom of HomePage to a company page or
  Watchlist) retained the previous scroll offset, causing new pages to open already scrolled
  down to the bottom. In `CompanyPage.jsx`, an asynchronous `behavior: 'smooth'` scroll
  caused the page to visibly mount at the bottom and animate upward.
- Fix:
  * Created `frontend/src/components/ScrollToTop.jsx` using React's `useLayoutEffect`,
    which runs synchronously *before* the browser paints the screen.
  * Enforced `window.history.scrollRestoration = 'manual'` to prevent browser scroll memory.
  * Executed synchronous scroll coordinate reset (`window.scrollTo({ top: 0, left: 0, behavior: 'instant' })`,
    `document.documentElement.scrollTop = 0`, `document.body.scrollTop = 0`) on every route
    path or search query change.
  * Mounted `<ScrollToTop />` globally at the root of `frontend/src/App.jsx`.
  * Removed the delayed post-render smooth scroll from `frontend/src/pages/CompanyPage.jsx`.

10. FULL-WIDTH EDGE-TO-EDGE RESPONSIVE SCREENER CHART (REMOVED CENTERED GUTTER):
   - Root Cause Diagnosis: The chart's SVG canvas had a hardcoded `svgW = 1000` with standard SVG `preserveAspectRatio="xMidYMid meet"`. In modern wide screens (1400px–1720px), the SVG letterboxed/pillarboxed itself into the center of the card, leaving ~250px of empty blank white space on the left and right while the surrounding toolbars stretched full width.
   - Dynamic Width Tracking: Attached a `ResizeObserver` on `containerRef` to dynamically measure the container's exact pixel width (`chartDimensions.width`) and height in real time.
   - Seamless Edge-to-Edge SVG: Configured `svgW = chartDimensions.width` and `preserveAspectRatio="none"` so the chart automatically fills 100% of the card from edge to edge on any viewport (mobile, tablet, desktop, or ultrawide).
   - Responsive Scale & Labels: Dynamically scaled X-axis date intervals (`maxDateLabels = Math.floor(plotW / 120)`), candle and volume bar widths, and ensured 1:1 crosshair cursor tracking with zero offset.
